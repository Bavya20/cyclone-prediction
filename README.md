# 🌪️ Spatio-Temporal Modeling for Cyclone Track Prediction

This project is a Machine Learning and Deep Learning based web application used to predict cyclone movement using historical weather data and spatio-temporal analysis.

## 📌 Project Description

Cyclones cause major damage to people and the environment. Predicting cyclone movement early helps in disaster management and safety planning.

In this project, different Machine Learning and Deep Learning models are used to predict cyclone direction based on meteorological parameters such as:

* Wind Speed
* Pressure
* Temperature
* Humidity
* Latitude
* Longitude

The models used are:

* Random Forest
* XGBoost
* ANN (Artificial Neural Network)
* LSTM (Long Short-Term Memory)

A simple web application was developed using Django where users can enter cyclone data and get prediction results.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone <your-repository-link>
```

### 2. Navigate to Project Folder

```bash
cd cyclone-track-prediction
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Mac/Linux

```bash
source venv/bin/activate
```

### 5. Install Requirements

```bash
pip install -r requirements.txt
```

### 6. Run the Server

```bash
python manage.py runserver
```

### 7. Open in Browser

```bash
http://127.0.0.1:8000/
```
